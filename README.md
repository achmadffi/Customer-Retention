# Customer Retention
SQL for Data Analyst

Project ini dibuat untuk mencari tahu persentase pelanggan yang tetap menggunakan produk atau layanan menggunakan SQL dan memberikan rekomendasi untuk mempertahankan pelanggan.

Dataset ini memiliki 5 kolom dan 500.000 baris data dengan detail kolom sebagai berikut:
1. customerid
2. orderdate
3. productid
4. orderid
5. totalsales

File yang tersedia diantaranya:
1. README.md
2. transaction_data_full.csv (Dataset)
3. Rasio Retention.sql (Query)
4. Rate Retention.pdf (Hasil dari project)
